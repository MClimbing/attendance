How to Turn On Location

Pick your phone and follow the steps, then reload this page.
iPhoneyour phone
  1. Open Settings → Privacy & Security → Location Services and make sure it's on.
  2. In that list, tap Safari Websites → choose While Using the App, and turn on Precise Location.
  3. Back on this page, tap the ≡ or aA icon in the address bar → Website Settings → Location → Allow.
  4. Reload this page, tap Check In, then tap Allow.
Using Chrome on iPhone? Go to Settings → Apps → Chrome → Location → While Using the App, with Precise Location on.
Androidyour phone
  1. Swipe down from the top of the screen and make sure Location is on.
  2. Open Settings → Apps → Chrome → Permissions → Location → Allow only while using the app, and turn on Use precise location.
  3. Back on this page, tap the icon to the left of the web address → Permissions (or Site settings) → Location → Allow.
  4. Reload this page, tap Check In, then tap Allow.
Your location is read once when you tap "Check In" and saved only with your check-in. Allow location access when your browser asks.
